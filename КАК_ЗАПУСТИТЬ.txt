TitanMod — быстрый старт

1) Скопируй .env.example → .env
2) Впиши:
   BOT_TOKEN=токен_от_BotFather
   BOT_ADMINS=твой_telegram_id
   AUTO_ACTIVATE=1

3) Установка:
   pip install -r requirements.txt
   python bot.py

4) Добавь бота в группу → сделай АДМИНОМ (бан, удаление, ограничение)

5) Проверка в группе:
   /ping
   /help
   /id
   /daily
   /ban (ответом на сообщение)

С AUTO_ACTIVATE=1 код /activate не обязателен.
Без него: владелец из BOT_ADMINS пишет любую команду — группа откроется сама.
